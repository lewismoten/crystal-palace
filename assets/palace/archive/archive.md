# Crystal Palace Archive

**Tic-tac-toe** is played on a three-by-three board. Take turns placing X and O. The first player to make a row, column, or diagonal wins.

- X moves first.
- Choose an empty square only.
- If all nine squares are full, the game is a draw.

> A strange game. The only winning move is not to play.

Crystal Palace borrows its Cold War control-room mood from *WarGames*: a fictional computer threatens missile conflict before learning the value of restraint. In that film, **Crystal Palace** is the NORAD call sign.

| Project | Role |
| --- | --- |
| Palace-9 | Strategic-fiction presentation experiment |
| Crystal-9 | Condensed mixture-of-experts neural model |
| Crystal Palace | The combined game and C64 experiment |

The Commodore 64 build is not a claim that an 1980s home computer can host a modern service. It is a bounded experiment: can original packed Crystal-9 mixture-of-experts weights be paged from a 1541 disk and evaluated in small fixed-point steps on period hardware?
